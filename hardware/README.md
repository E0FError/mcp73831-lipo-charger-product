# Hardware sources (Altium Designer)

Altium Designer project for the **DTU LiPo Charger v1.0** (Group 11).

| File | Contents |
|---|---|
| `DTU_LiPo_Charger_v1.0.PrjPcb` | Altium project — **open this file** |
| `Top.SchDoc` | Top-level hierarchical sheet |
| `charger_IC.SchDoc` | MCP73831 charger block |
| `adj_current.SchDoc` | DIP switch + preset `R_PROG` resistors |
| `connect.SchDoc` | USB-C, headers and JST battery connector |
| `DTU_LiPo_Charger_v1.0.PcbDoc` | Two-layer PCB layout |
| `LiPo_Charger.SchLib` | Schematic symbols |
| `LiPo_Charger.PcbLib` | PCB footprints |

## Opening the project

1. Open **Altium Designer**.
2. `File → Open` and select `DTU_LiPo_Charger_v1.0.PrjPcb`.
3. The hierarchical schematic and PCB documents load automatically.

## Notes

- Altium artefacts (`__Previews/`, `History/`, `Project Logs*/`,
  `Project Outputs*/`) are excluded via `.gitignore` and will be regenerated by
  Altium when the project is opened.
- The schematic images in `../images/` were extracted from Altium's cached
  previews with [`../tools/altium_preview_to_png.py`](../tools/altium_preview_to_png.py);
  the 3D render is taken from the team's user guide.
